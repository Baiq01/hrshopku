# HRShopku - Baju Bodo E-commerce

Monorepo starter untuk aplikasi penjualan Baju Bodo (Sulawesi Selatan) menggunakan Laravel (backend API + admin) dan React.js (frontend). Pembayaran diintegrasikan dengan Midtrans (Snap).

Isi:
- backend/ - Laravel API skeleton
- frontend/ - React app

Lihat README masing-masing folder untuk instruksi instalasi.
